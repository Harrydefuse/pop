# Rank art

Anything here overrides the art the agent downloads from Riot. Files are named
after the competitive tier number.

Immortal and Radiant art is already installed:

| File | Rank |
|---|---|
| `24.png` | Immortal 1 |
| `25.png` | Immortal 2 |
| `26.png` | Immortal 3 |
| `27.png` | Radiant |

To swap one out, replace the file and restart the agent. `.png`, `.svg`,
`.webp` and `.jpg` all work. Art is trimmed of transparent padding and centred
on a square canvas so every rank renders at the same size — worth doing to any
replacement, or that rank will look bigger or smaller than its neighbours.

Full tier numbering, for any rank below Immortal: 3-5 Iron 1-3, 6-8 Bronze,
9-11 Silver, 12-14 Gold, 15-17 Platinum, 18-20 Diamond, 21-23 Ascendant,
24-26 Immortal, 27 Radiant.
