# Drop-in rank art

Anything you put here overrides the rank art the agent downloads from Riot.
Name the file after the competitive tier number:

| File | Rank |
|---|---|
| `24.png` | Immortal 1 |
| `25.png` | Immortal 2 |
| `26.png` | Immortal 3 |
| `27.png` | Radiant |

`.png`, `.svg`, `.webp` and `.jpg` all work. Square images look best; the
overlay scales them to fit. Restart the agent after adding a file.

Full tier numbering, if you need a lower rank: 3–5 Iron 1–3, 6–8 Bronze,
9–11 Silver, 12–14 Gold, 15–17 Platinum, 18–20 Diamond, 21–23 Ascendant,
24–26 Immortal, 27 Radiant.
